Compact package: Final map + waypoint navigation program
For Ubuntu VM with ROS 2 Humble, TurtleBot 4 navigation/viz, and Nav2 installed.

1. Automatic 1-Step Bringup (Recommended):
~/Robot-Needs-Vision/Stage2/vm_map_tools/auto_nav_bringup.sh
(Checks /odom and /scan hardware connectivity, cleans stale FastDDS cache, launches localization, Nav2, and software-accelerated RViz with a single command).

2. Manual 3-Terminal Bringup (Alternative):
Run in three separate terminals on Ubuntu:
Terminal 1:
source /opt/ros/humble/setup.bash
source ~/turtlebot4_ws/install/setup.bash
ros2 launch turtlebot4_navigation localization.launch.py \
    map:=$HOME/Robot-Needs-Vision/Stage2/vm_map_tools/maps/final_room.yaml \
    params:=$HOME/Robot-Needs-Vision/Stage2/vm_map_tools/maps/localization_params.yaml

Terminal 2:
source /opt/ros/humble/setup.bash
source ~/turtlebot4_ws/install/setup.bash
ros2 launch turtlebot4_navigation nav2.launch.py

Terminal 3:
source /opt/ros/humble/setup.bash
source ~/turtlebot4_ws/install/setup.bash
export LIBGL_ALWAYS_SOFTWARE=1
ros2 launch turtlebot4_viz view_robot.launch.py

3. Confirm that the VM receives the robot's /scan, /odom, and TF.
RViz Fixed Frame defaults to map. Use 2D Pose Estimate to align the laser scan with the map walls.

4. Run the camera keypoint collector in a 4th terminal:
source /opt/ros/humble/setup.bash
cd ~/Robot-Needs-Vision/Stage2/vm_map_tools
python3 camera_keypoints.py --map maps/final_room.yaml --points maps/stage2_keypoints.json

5. On your Windows laptop (to stream laptop USB camera):
python Stage2\laptop_camera_sender.py --single-cam 0
(Auto-discovery is enabled by default; it finds the VM IP across NAT or Bridged automatically).

6. Keypoint commands in the terminal:
SAVE A 0.5    - Save current robot pose under keypoint name with visibility (0.0 to 1.0)
GOTO 0        - Send robot to keypoint ID 0 to verify navigation
LIST          - Display all saved keypoints
DELETE 0      - Delete keypoint ID 0
STATUS        - Check robot pose and camera stream status
CANCEL        - Cancel active navigation
QUIT          - Save and exit
